A

Plugin-chain trace

Horizontal flow of nodes (persona → ai-mcp-oauth2 → ACL → exchange → OPA → upstream) that light green/red. Teaches "governance happens IN the gateway" — great for the exchange & OPA steps too.

B

Request / Response console

Familiar API-console split with a compact "verdict" strip of badges. Lower novelty, very legible, closest to what devs already know.

C

Hybrid: trace on top, req/resp below

The flow diagram as the hero, with an expandable request/response + raw token panel underneath for the detail-oriented. Best of both; a bit more screen real estate.
