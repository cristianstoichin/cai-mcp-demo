| 2026-07-22 (U8) | demo-ui verdict taxonomy is **coarse** (5 verdicts): a `403` that isn't `{"message":"unauthorized"}` classifies as `acl-deny`, which covers BOTH the MCP tool-ACL deny and the REST OIDC scope/audience 403 (both surface as Kong `{"message":"Forbidden"}`). | 2026-07-22 (U9) | **Reverses U6.** demo-ui is now ALSO a **Compose service** (`demo-ui`, multi-stage Dockerfile mirroring the aegis dashboard) so `docker compose up` runs the whole demo in one command; it reaches Kong/Keycloak on the in-network hostnames (`kong-dp:8000`, `keycloak:8080`), published host-local on `127.0.0.1:4000`. `scripts/ui.sh` host-run mode is RETAINED. **Split by capability:** Demo/Explore/Registry/Exchange work identically in both modes; Stack-mode **execute** actions (up/down/sync/scripts) are **host-only** (disabled in-container behind a `UI_IN_CONTAINER` guard + a UI note), because a container must not tear down its own compose project — its `down` would kill itself. Trade-offs: adds a read-only docker-socket mount (local demo, standard) + `docker-cli` in the image (for status). U6's host-run rationale (Stack must shell out to the host) still holds — hence ui.sh stays. | demo-ui arch | [[U6]] docker-compose.yaml, demo-ui/Dockerfile, README |
